# 本地问题恢复表

已授权任务中，已知本地问题由 Agent 诊断、最小修复并继续。每次重试必须有实际变化。保留可验证的提取基线和未改动译文，只重做受影响内容。遇到真正缺少的输入或无法恢复的问题才询问用户。

| 现象 | 本地处理 |
| --- | --- |
| 运行库/LPAC 导入失败 | 使用本安装的 CPython 3.12.14 与精确匹配的兼容 wheelhouse；保持 `--no-sync`。核对安装清单，依赖发生变化才重装匹配包。 |
| pdfminer 版本查询触发 socket | 使用现有精确哈希绑定的版本入口适配器；未知版本先核对，不能开放网络能力。 |
| CFFI 空 RT_MANIFEST 导致导入失败 | 恢复已验证的同版本兼容构建；保留沙箱策略，不替换系统运行库。 |
| 合法 Pattern/设备颜色空间被拒绝 | 使用现有资源声明解析修复；图像像素计数规则仍保持严格。 |
| 三线表、组合图、上下标、浮动图注分割异常 | 对照局部源页诊断，使用已纳入源码的提取修复；改动后只跑对应合成用例并重新提取受影响输入。 |
| 机械检查误报自然中文表达 | 查看具体单元与 issue_hash；修正错误，或对启发式语言标记提供实际局部复核依据。确切数字/引用错误不能直接消除。 |
| 核心词汇/图表解读缺失 | 补充对应段落或题注的必要候选，重新 assemble；不重译其他段落。 |
| 排版或字体问题 | 复用译文与 EXTRACTED 基线；修正布局或采用不改变含义的可读符号表达，然后重新 finish。 |
| 输出文件已存在 | 使用明确的修订文件名重新完成，不覆盖未验证的既有成品。 |

`finish_job.py` 对可恢复失败保留提取基线一小时，输出稳定的 RECOVER 动作；每次完成尝试使用独立目录。成功后自动清理受管目录。用户论文、译文和任意错误原文不得写入本表。若失败没有进展，应换一种有证据的诊断；缺少必要输入时报告具体缺项，不重复索要既有授权。
