# Public release-evidence records

This directory is reserved for sanitized Markdown records that can be reviewed
in a public release. This README is guidance only and does not resolve any
release blocker.

An approved record must be non-empty, remain below the repository evidence-size
limit, and contain a standalone `Evidence-ID: <blocker-id>` line matching the
blocker that cites it. Do not add private credentials, confidential legal
documents, personal data, or unverified claims here.

Under the personal-project policy revised on 2026-09-09, one verified private
route may receive both conduct and security reports. A record should describe
the route's supported purposes, the responsible role, how and when availability
and privacy were checked, and the result. The address or link is intended for
publication, but raw reports, messages, account secrets, and private recipient
details are not. Record limitations on independent review honestly; no
independent alternate contact is required.

Maintainer evidence may use a confirmed GitHub public name and a truthful role
statement; a legal name or identity document is not required for that record.
The public maintainer identity does not establish ownership of a brand asset.
No identity, route, or asset-rights evidence has been supplied by this guidance.
