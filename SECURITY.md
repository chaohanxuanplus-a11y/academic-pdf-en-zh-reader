# Security Policy

## Supported versions

There are currently no supported public versions. The project is under local
development and must not be published as a production-ready Skill.

## Reporting a vulnerability

Contact the maintainer, `chaohanxuan`, privately at
[chx2391898642@126.com](mailto:chx2391898642@126.com) for security or
code-of-conduct reports. The maintainer supplied this address on 2026-09-10;
the configuration record is in `compliance/release-status.json`. No test email
has been sent, so delivery and response times have not been independently tested.

The personal-project policy revised on 2026-09-09 allows one verified private
route to receive both security and code-of-conduct reports, provided the route
actually supports both purposes. A separate security mailbox or an independent
alternate contact is not required. The route's address or link will be public;
the report content and reporter details must not be posted publicly. Reports
are handled by a personal maintainer on a best-effort basis, without a fixed
response-time guarantee or an independent review service.

Public issues are not an acceptable channel for vulnerabilities, user papers,
personal information, secrets, or unredacted logs. No placeholder email or an
upstream project's contact address may be presented as this project's channel.

Before a public release, this file must be updated with supported versions, the
coordinated disclosure expectations, and the fix publication process. The
configured mailbox does not clear the remaining production safety gate.
