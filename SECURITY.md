# Security Policy

## Supported versions

There are currently no supported public versions. The project is under local
development and must not be published as a production-ready Skill.

## Reporting a vulnerability

A verified private security-reporting channel has not yet been configured. Do
not publish this repository or invite external security reports until GitHub
Private Vulnerability Reporting or an equivalent private channel has been
enabled and recorded in `compliance/release-status.json`.

Public issues are not an acceptable channel for vulnerabilities, user papers,
personal information, secrets, or unredacted logs. No placeholder email or an
upstream project's contact address may be presented as this project's channel.

Before a public release, this file must be updated with supported versions, the
real private reporting route, acknowledgement and triage targets, coordinated
disclosure expectations, and the fix publication process.
